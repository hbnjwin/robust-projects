# qt-ghactions-ci-claude

Quantitative trading framework with backtesting, portfolio management, and analytics.

## Quick Start

```bash
# Install all dependencies (including dev tools)
make install

# Run linter
make lint

# Run tests with coverage
make test

# Run type checker
make typecheck
```
