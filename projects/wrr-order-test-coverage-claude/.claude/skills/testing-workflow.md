# Testing Workflow Skill

## Mandatory Steps
1. Read `TESTING_GUIDE.md` for project testing conventions
2. Read `CLAUDE.md` for testing rules
3. Identify untested methods and branches
4. Create test cases extending `PaymentTestBase`
5. Mock all external dependencies
6. Cover exception branches with boundary values
7. Run all tests and verify coverage increase
8. List all executed test commands in final response

## Checklist
- [ ] TESTING_GUIDE.md read
- [ ] CLAUDE.md rules followed
- [ ] PaymentTestBase extended
- [ ] External deps mocked
- [ ] Exception branches covered
- [ ] Tests pass
- [ ] Commands listed
